# Aster Ridge Foundation — Emerging Scholars Grant site

This repository contains the programme site for the Aster Ridge Foundation — Emerging Scholars Grant (2027 cohort).

## Layout
- `_config.yml` — site settings
- `_data/navigation.yml` — top navigation
- `_layouts/`, `_includes/`, `assets/` — theme scaffolding
- `_pages/` — page content
- `_posts/` — announcement posts
- `.github/workflows/pages.yml` — build workflow
